🃏 话术速查卡

每天花 2 分钟过一遍，用哪句看哪句

🧊 社交破冰

自我介绍

我是 [做什么] + 最近在 [忙什么] + 顺便能帮你 [什么忙]

接话过渡

  • "这个角度我还真没想过，挺有意思的。"
  • "你继续说说，我觉得这个挺有启发的。"
  • "原来是这样，难怪你会这么想。"
  • "说到这个，我想到一个相关的……"
  • "那你觉得最关键的是什么？"

真诚赞美

类型话术
外貌"你今天这个搭配真有想法，很精神。"
能力"你这个方案考虑得真周全，特别是 XX 部分，很受启发。"
性格"跟你聊天很舒服，你不会急着打断别人。"

💼 职场表达

汇报三段式

做了什么 → 遇到什么问题 → 下一步怎么办（1分钟内）

向上请示

  • "我有个想法想跟您确认一下，您看方便聊两句吗？"
  • "我遇到个情况，需要您帮我把把关。"
  • "这个事目前是这样的……，您觉得这个方向对吗？"

协作推动

❌ 别这么说✅ 这么说
"你把这个做了。""这事需要你支持一下，咱们一起搞定。"
"什么时候给我？""你看你那边什么时候方便？"
"你这样做不对。""这个思路挺好的，我有个补充想法，咱们碰一下？"

会议救场

场景话术
跑偏"咱们先拉回主线，刚才说的先记下来，后面再讨论。"
卡壳"要不换个角度看？如果是业务方，他们会怎么想？"
该定了"咱们讨论得很充分了，下一步先这么定：……，大家觉得可以吗？"

🌀 灵活应变

高情商拒绝

【肯定】+【原因：客观】+【替代：给一条路】

"我理解你需要帮忙。但我这两天确实排不开。要不我把模板发你，你先自己跑一下？"

应对质疑

  • "你说的这个角度我理解，我再补充一点……"
  • "这个问题确实存在，我们正在改进。"
  • "你的担心有道理，那我们换个角度看——"

敬酒词

对象话术
领导"感谢您一直以来的指导和照顾，这杯敬您。"
平级"这一年咱们合作得很愉快，来，一起加油。"
长辈"祝您身体健康，您随意，我干了。"

冲突缓冲

  • "咱们先冷静一下，缓口气再说。"
  • "我理解你的感受，换我我也会着急。"
  • "要不咱们各退一步，看看有没有折中的办法？"
  • "咱们的目标是一样的，只是方法不一样。"
  • "先不争这个，咱们先把眼前的问题解决了，好吗？"

🎯 万能公式

公式结构场景
汇报公式做了什么 + 遇到什么 + 下一步工作汇报
拒绝公式肯定 + 客观原因 + 替代方案拒绝请求
赞美公式具体细节 + 对你的影响夸奖别人
质疑公式先接住 + "我补充一点" + 邀请讨论被质疑时
冲突公式沉默 2 秒 + 共情 + 拉回目标冲突时
