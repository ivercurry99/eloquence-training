# 02 · 功能清单（Feature List）

> 原则：一个 feature 完成并过门禁，再进入下一个。
> UI 基线：vibe-hub.org 风格（蓝紫主色 #4B3FE3、白卡片、毛玻璃吸顶导航、12-18px 圆角、柔和多层阴影、状态色 绿#2CB07F/橙#C46F0B/红#C9382F、深色模式）。

## F0 · 工程地基（Priority: P0）
- [ ] Vite + Vue 3 + Pinia + Vue Router 项目初始化
- [ ] 设计令牌系统（颜色/圆角/阴影/间距 CSS 变量，亮暗双主题）
- [ ] 布局骨架：毛玻璃吸顶导航 + 路由页面容器 + 移动端适配
- 验收：`npm run build` 产出纯静态文件；空路由页可切换；暗色模式可切换。

## F1 · 14 天训练计划（Priority: P1）
- [ ] 4 阶段（社交破冰/职场表达/灵活应变/内化巩固）× 14 天卡片网格
- [ ] 每日详情：目标 / 话术模板 / 核心话术 / 对话示例 / 练习流程 / 自检清单 / 笔记
- [ ] 完成标记 + 总进度条 + 阶段进度
- [ ] 内容数据沿用旧版 `legacy/data.js`（14 天全量），迁移为 JSON 模块
- 验收：点任意天卡片弹详情；标记完成后进度条联动；刷新不丢状态。

## F2 · 话术速查卡（Priority: P1）
- [ ] 按 4 大场景分组（社交破冰/职场表达/灵活应变/万能公式）浏览
- [ ] 关键词搜索（即时过滤）
- [ ] 卡片支持「加入复习」
- 验收：搜索"拒绝"能过滤出拒绝相关话术；无结果有空状态。

## F3 · 间隔重复复习 SRS（Priority: P2）
- [ ] 艾宾浩斯间隔：1/2/4/7/15 天，到期卡片进入「今日待复习」
- [ ] 复习交互：显示话术场景 → 用户回忆 → 翻面看答案 → 自评（记住/模糊/忘了）
- [ ] 自评结果重置间隔；连续「记住」毕业后归档
- 验收：加入卡片后按规则到期；自评「忘了」回到 1 天间隔。

## F4 · 打卡记录与笔记（Priority: P1）
- [ ] 每日 3 项 checklist + 笔记 textarea，实时保存
- [ ] 首次启动自动检测旧版 localStorage（键 `eloquence-training-data`）并迁移打卡/笔记/金句/进度
- [ ] 迁移结果一次性提示（迁移了几条）
- 验收：用旧版数据结构 mock 后刷新，打卡状态与金句完整出现在新版。

## F5 · 语音练习评分（Priority: P1）
- [ ] 选 Day → 选话术 → Web Speech API 录音识别（zh-CN）
- [ ] 评分：准确率（逐字对比）+ 完整度 + 流利度（编辑距离），加权总分
- [ ] 练习历史列表（最近 20 条）
- 降级：浏览器不支持语音识别时给出明确提示并禁用按钮
- 验收：说一段话出评分；历史可回看；不支持的浏览器有友好降级。

## F6 · AI 对话陪练：角色扮演 + 辩论（Priority: P2）
- [ ] 场景角色：领导请示 / 面试官 / 客户质疑 / 酒局应酬 / 朋友冲突
- [ ] 辩论模式：AI 持反方立场，就给定辩题攻防数回合
- [ ] 对话结束后 AI 给结构化反馈（亮点/问题/建议话术）
- [ ] API Key 用户自配（设置页输入，仅存 localStorage；支持 OpenAI 兼容接口：地址+Key+模型名）
- 降级：未配置 Key 时展示配置引导，其余功能不受影响
- 验收：配 Key 后可完成一轮 5+ 轮对话并收到反馈；无 Key 时有引导。

## F7 · 朗读训练（Priority: P2）
- [ ] 内置素材：绕口令（分级）+ 美文段落 + 金句
- [ ] 朗读录音 → 识别 → 与原文对比评分（准确率/漏字/多字）
- [ ] 每篇历史最佳分数
- 验收：读绕口令后出对比高亮（错字标红）；最佳分刷新保存。

## F8 · 即兴演讲挑战（Priority: P2）
- [ ] 随机抽题（职场/社交/观点类题库 50+）
- [ ] 30 秒准备倒计时 + 60/90 秒演讲倒计时
- [ ] 录音识别 → 字数/语速/填充词（嗯/啊/然后）统计
- [ ] 自评 + 历史记录
- 验收：完整跑一轮挑战，各计时与统计正确入库。

## F9 · 学习进度统计（Priority: P2）
- [ ] 打卡热力图（GitHub 风格，近 3 个月）
- [ ] 练习时长/次数周趋势图
- [ ] 五维雷达图（流畅/应变/赞美/拒绝/汇报场景掌握度，按练习记录推导）
- [ ] 14 天总评星级 + 收获笔记（沿用旧版）
- 验收：造 30 天假数据后三图正确渲染；无数据有空状态。

## F10 · 设置与数据管理（Priority: P2）
- [ ] AI API 配置（地址/Key/模型，连接测试）
- [ ] 数据导出/导入 JSON（全量备份）
- [ ] 深色模式切换（跟随系统/手动）
- [ ] 清空数据（二次确认）
- 验收：导出再导入后数据一致；Key 不出现在导出文件。

## 功能拆分粒度
- 每个 feature 必须能被「架构师→开发者→测试员→审查员」独立走完一轮。
- 超过 3 天/30 文件的 feature 必须再拆小。
